📘 Project Overview

This project showcases how a fine-tuned YOLOv11 model (yolo11n.pt) can be integrated into a Flask web application for real-time object detection. The app allows users to perform live webcam detection or upload files for analysis.

🧠 About YOLO

YOLO (You Only Look Once) is an advanced real-time object detection model. It analyses an image in a single pass and identifies multiple objects efficiently.

ModelDescriptionSpeedAccuracy
yolov8n.ptNano – lightweight for edge devices🔥 FastestLow
yolov8s.ptSmall – good balance of speed and accuracy⚡ FastMedium
yolov8m.ptMedium – improved precisionAverageGood

🔬 Fine-Tuning Process

  1. Prepare dataset and annotations (YOLO format).
  2. Start training from a pre-trained model using Ultralytics:
    3. from ultralytics import YOLO
model = YOLO('yolov8s.pt')
model.train(data='data.yaml', epochs=50, imgsz=640)
  3. Evaluate metrics (precision, recall, mAP).
  4. Save the best model as yolo11n.pt and use for inference.

⚙️ Project Workflow

  • User uploads or streams input from webcam.
  • The Flask backend loads yolo11n.pt.
  • YOLO detects objects and draws bounding boxes.
  • Processed results are displayed and saved.
